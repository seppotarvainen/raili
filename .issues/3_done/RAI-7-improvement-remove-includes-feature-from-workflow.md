# RAI-7: Remove includes feature from workflow

**Type:** improvement

## Description
The workflow "include" (sub-workflow) feature hides workflow behavior by merging external files into the main workflow, which makes workflows harder to understand and reason about. Remove the includes functionality (runtime merging and schema support), update documentation and tests, and ensure the engine fails fast on unknown top-level fields instead.
